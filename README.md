# SUBENUM

**SUBENUM** is a simple Bash-based subdomain enumeration tool that automates the process of discovering subdomains using **Assetfinder** and checking their availability using **Httprobe**.

### Features

* Animated terminal interface
* Finds subdomains using Assetfinder
* Checks live HTTP/HTTPS hosts using Httprobe
* Saves discovered subdomains and live hosts into separate files
* Simple and beginner-friendly Bash script

### Tools Used

* Bash
* Assetfinder
* Httprobe

**Note:** Use this tool only on domains you own or have permission to test.
